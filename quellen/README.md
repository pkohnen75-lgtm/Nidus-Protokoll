# Quellenablage

Jede Quelleninstanz hat ein eigenes Verzeichnis. `text.txt` enthält den unverändert gespeicherten Connector-Textextrakt oder die gesondert extrahierte Textdarstellung einer lokalen Datei. `original.*` ist eine byteidentische lokale Originalkopie, soweit vorhanden. `native-document.json` sichert bei Google Docs den angebotenen strukturierten Dokumentstand einschließlich Tabs. `metadaten.json` dokumentiert Darstellung, Herkunft und Prüfsummen.

Die Textextraktion ersetzt keine vollständige Originaldatei. Vor allem PDF-Lesereihenfolge, Tabellen, Bilder, Kommentare, Änderungsvorschläge und nicht erreichbare Revisionen müssen gesondert betrachtet werden. Es wurden keine Texte korrigiert, zusammengezogen oder als verbindliche Neufassung ausgegeben.
