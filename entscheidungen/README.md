# Redaktionelle Entscheidungen

## 2026-09-09 – Quellen erhalten und erschließen

Auftrag: NIDUS-Sachtexte nachvollziehbar für GitHub ordnen, ohne stille Inhaltsänderungen oder Löschungen. Umsetzung: getrennte Quelleninstanzen, Themenindizes, maschinenlesbare Metadaten und Konfliktregister. Diese Entscheidung verändert keine NIDUS-Grundregel.

## 2026-09-09 – Umfang der Veröffentlichung

Persönliche Reflexionen, Korrespondenz sowie Musik- und Covertexte werden auf ausdrücklichen Wunsch nicht für die Nachwelt in dieses Repository aufgenommen. Sie werden auch nicht mit Titeln oder Einzelverweisen im öffentlichen Katalog aufgelistet. Die Originale bleiben unverändert.

## 2026-09-09 – Keine automatische Ratifizierung

Selbstbezeichnungen wie „Final“, „Stabil“ oder „Verbindliche Charta-Struktur“ werden als Quellenangaben erhalten. Der bisherige GitHub-Manifesttext wird als historisch als ratifiziert bezeichnet dokumentiert. Keine andere Fassung wird aufgrund dieses Imports zur gültigen Verfassung erklärt.

## 2026-09-09 – Portabler Zugriff auf historischen Dateinamen

Der bestehende Manifest-Dateiname enthält einen Doppelpunkt und kann unter Windows nicht ausgecheckt werden. Der unveränderte Inhalt wird auf dem neuen Arbeitsbranch nach `quellen/github-manifest-v1-3/original.md` verlagert. Vorheriger und neuer Git-Blob sind identisch; es geht kein Inhalt verloren. Alle bisherigen Commits einschließlich des alten Pfads bleiben erhalten. Die reversible Umordnung ist im Änderungsvorschlag als Umbenennung prüfbar. Damit lässt sich die neue Repository-Struktur auch unter Windows auschecken.

## Vorlage für künftige Entscheidungen

Datum, Anlass, betroffene Dokument-IDs und Prüfsummen, Entscheidung, Begründung, Beleg, Status vorher/nachher, Nachfolger/Vorgänger, offene Einwände. Entscheidungen über inhaltliche Gültigkeit müssen von reiner Ablagepflege unterschieden werden.
